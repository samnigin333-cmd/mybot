# KORPORATIV BOT — O'RNATISH YO'RIQNOMASI

## 1. TAYYORGARLIK

Bot fayllarini kompyuterga ko'chirish:
- Barcha fayllarni bitta papkaga joylashtiring (masalan: C:\mybot\)

## 2. BOT TOKENINI KIRITISH

`bot.py` faylini Notepad bilan oching va:
```
TOKEN = "BU_YERGA_BOT_TOKENINGIZNI_YOZING"
```
o'rniga haqiqiy tokeningizni yozing.

Telegram ID ni ham to'g'rilang:
```
MY_TELEGRAM_ID = 1131598666
```

## 3. O'RNATISH

`install.bat` faylini ikki marta bosing — desktop'da yorliq yaratiladi.

## 4. ISHGA TUSHIRISH

Desktop'dagi **"Korporativ Bot"** yorlig'ini ikki marta bosing.

---

## BOT IMKONIYATLARI

### Admin uchun:
- ➕ Ishchi qo'shish (login/parol bilan)
- ❌ Ishchi o'chirish
- 🔑 Parol o'zgartirish
- ⭐ KPI belgilash (izoh bilan)
- 🕐 Ish soat belgilash
- 📋 Bugungi hisobotlarni ko'rish
- 📊 Oylik hisobot ko'rish
- 📅 Davomat ko'rish
- 💾 Eksport: Word / Excel / PDF

### Ishchi uchun:
- 🔑 Login/parol bilan kirish
- 📝 Kunlik hisobot yozish (rasm bilan)
- 🟢 Keldi / 🔴 Ketdi belgilash
- ⭐ O'z KPI ballarini ko'rish
- 🕐 Ish soatini ko'rish
- 📊 Statistikani ko'rish
